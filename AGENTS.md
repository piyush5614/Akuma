# Agent conventions

- Read `docs/MASTER_PROMPT.md`, `docs/PROGRESS.md`, and `docs/DECISIONS.md`
  before starting a new part.
- Keep backend rules as the single source of truth.
- Do not commit secrets; use `.env.example`.
- Run the smallest relevant test and report its real result.
- Update progress and decisions when behavior or tooling changes.

## Common commands

Use `make help` to list project commands. On Windows without GNU Make, run the
equivalent Python or Docker command directly.
